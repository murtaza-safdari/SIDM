# Run 3 signal validation

`era_fingerprint.py` checks, from the content of the LLPNanoAOD files alone, that the private Run 3 production is at 13.6 TeV and that each era carries its own conditions. It reads the 200 GeV / 1.2 GeV / 4.8 mm point of both channels (120 chunks, 100k events per sample and era). sqrt(s) is computed as m(B_s)/sqrt(x1 x2), cross-checked against twice the beam energy from the LHE incoming partons, and compared with the generator `comEnergy`. It also measures the pileup profile, the generated and reconstructed vertex positions, and the HLT branch content. The global tag, CMSSW release and HLT menu of every processing step are read from the file's `ParameterSets` and `MetaData` trees, matching PSet IDs by MD5. Two maps show the era-specific dead regions: the 2022EE ECAL endcap region (e/gamma efficiency of gen electrons, 2Mu2E) and the 2023BPix pixel sector (mean nTrackerLayers of matched muons). Usage: `python era_fingerprint.py --eras 2022,2022EE,2023,2023BPix` writes `era_fingerprint.csv` (one row per era), `era_fingerprint.npz` (the histograms; add `--replot` to redraw without EOS) and vector PDFs in `figures/`. The m/sqrt(x1 x2) estimator has a ~2.5% low tail, which is not a beam-energy effect: about 98% of events are c-cbar initiated (2022 4Mu, four chunks), and in the tail events the low-x (x < 1.1e-3) charm parton's mass is not negligible. The LHE estimate has no such tail (99.8% of events within 13598.6-13600.6 GeV).
